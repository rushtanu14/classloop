# ClassLoop Brand Assets

Use these assets for ClassLoop product, website, release, and support surfaces.

- `classloop-logo-horizontal.svg` - primary logo lockup for light backgrounds.
- `classloop-logo-horizontal-light.svg` - primary logo lockup for dark backgrounds.
- `classloop-logo-stacked.svg` - centered logo for square or tall placements.
- `classloop-wordmark.svg` - text-only wordmark.
- `classloop-mark.svg` - transparent standalone mark.
- `classloop-app-icon.svg` - production app icon source.
- `classloop-icon-*.png` - PNG app icon exports.
- `../classloop-brand-assets.zip` - packaged copy of this folder.

Brand colors:

- Ink: `#0f172a`
- Primary green: `#10b981`
- Teal: `#37d6c7`
- Sky: `#6cc4ff`
- Lime accent: `#e7f37a`
- Warm surface: `#fffefa`
