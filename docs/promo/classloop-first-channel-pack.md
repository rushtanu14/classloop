# ClassLoop First Channel Pack

Last updated: 2026-06-01

This pack turns the ClassLoop north star into simple posts that can start a channel before ReelFarm-style automation exists. The goal is not polished advertising. The goal is proof: teachers, tutors, and club leads should see the messy-input-to-student-follow-up transformation and understand why it saves time.

## Channel Positioning

Working channel promise:

> ClassLoop turns messy class records into teacher-reviewed student follow-ups.

Use this framing repeatedly:

- Teacher-specific: after-class follow-up, transcripts, rosters, resources, student next steps.
- Broad enough to try: teachers, tutors, club leads, workshops, study groups, and personal meeting notes.
- Trust-first: AI drafts, teacher approves, students see only their own next steps.
- Privacy-aware: demo data online, desktop/pilot path for real class records.

Avoid this framing:

- "AI replaces teachers."
- "Automatic grading."
- "Student ranking."
- "Upload real student data to the public demo."
- "Fully school-approved" before legal/pilot review is actually done.

## Posting Cadence

Start with a two-post weekly cadence:

- Monday: short transformation clip, 30 to 50 seconds.
- Thursday: short proof or build-in-public clip, 20 to 40 seconds.
- Every other week: repost the starter deck as a carousel or narrated mini-walkthrough.

Each post should include:

- A teacher pain hook.
- One product action on screen.
- One trust boundary.
- One ask for beta feedback.

## Visual Asset Checklist

Capture these once, then reuse them:

- Hosted homepage first viewport.
- Hosted public demo first viewport (`https://classloop-followup.vercel.app`).
- Teacher import/paste screen.
- Generated teacher review screen.
- Warning or unmatched speaker state.
- Student dashboard.
- Completion review.
- Download/PWA page.
- Starter promo deck cover slide.

Use sample/demo or anonymized data only. Do not record raw real-student transcripts, full rosters, grades, emails, or private notes.

## Starter Post 1: Messy Transcript To Follow-Up

Format: 45-second vertical screen recording.

Hook:

> Teachers should not have to turn a Zoom transcript into 30 separate reminders.

Shot list:

| Time | Screen | Voiceover |
| --- | --- | --- |
| 0:00-0:04 | Raw transcript / notes visible, sample data only | "This is what after-class cleanup looks like right now." |
| 0:04-0:10 | Paste transcript and roster into ClassLoop | "A transcript, a roster, notes, and a few links all live in different places." |
| 0:10-0:18 | Generate draft / teacher review | "ClassLoop pulls out the recap, tasks, resources, and student-specific follow-ups." |
| 0:18-0:28 | Unmatched speaker or review warning | "The important part is the teacher review step. It flags things to check before students see anything." |
| 0:28-0:38 | Student dashboard preview | "Then each student gets a clean next step: what happened, what they owe, and what helps." |
| 0:38-0:45 | Demo URL or deck cover | "I am looking for teachers and tutors to test this with anonymized class records." |

Caption:

> Building ClassLoop: a teacher assistant for the work after class. It turns messy transcripts, rosters, notes, and links into teacher-reviewed student follow-ups. Sample/demo data only for public clips. Teachers/tutors: would this save you time after a session?

CTA:

> Comment "beta" or send a workflow you want tested.

## Beta Feedback Ask

Use this short message in comments, posts, or DMs:

> I am testing ClassLoop with teachers/tutors using sample or anonymized class records. The test takes about 15 minutes: paste a transcript or notes, review the generated recap/tasks/student follow-ups, and tell me what is wrong, confusing, or actually useful. No raw student records in public demos.

For direct email/DM outreach, use [classloop-beta-outreach-kit.md](classloop-beta-outreach-kit.md). Track interested testers in [classloop-beta-tester-tracker.csv](classloop-beta-tester-tracker.csv).

## ReelFarm Handoff Later

When automating this later, each post should have these fields:

- Hook.
- Target audience.
- Raw clip or screenshot source.
- Voiceover text.
- On-screen text.
- Caption.
- CTA.
- Privacy label: sample, anonymized, or private-only.
- Product route shown.
- Follow-up metric: views, comments, beta replies, or tester booked.

ReelFarm should optimize packaging, not invent product claims. Keep the trust boundary and sample-data boundary in every generated promo batch.
