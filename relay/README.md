# Relay

Relay is a standalone hackathon submission app focused only on personal meeting follow-up. Paste meeting minutes, add the meeting title, date, context, resources, questions, and due dates, then generate an individual recap and task list.

## Commands

- `npm run dev`
- `npm run build`
- `npm run test`
- `npm run test:browser`

Relay intentionally stays focused on one person's meeting follow-up rather than role-based collaboration or roster workflows.
